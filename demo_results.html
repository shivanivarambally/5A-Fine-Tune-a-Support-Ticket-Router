Support Ticket Router Demo Results

A self-contained companion page for the Week 5 demo. It records the two fine-tuning iterations, the latest corrected evaluation, and the evidence to show during the walkthrough.

Result: the latest fine-tuned model reached 70.7% validation accuracy versus 31.6% for the base model, a gain of 39.1 percentage points.

Conclusion

  • Fine-tuning improved the latest model from 31.6% to 70.7% accuracy.
  • The latest model is a successful prototype with macro F1 of 0.710.
  • EOL, Fileservice, and Active Directory are the strongest current routing areas.
  • Computer-Services is the main remaining weakness.
  • A fair comparison of both iterations requires the same fixed test set.
